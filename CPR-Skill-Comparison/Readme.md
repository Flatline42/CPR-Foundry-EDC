Crew skill comparison- I crib from Delta Green and run a houserule that if your base score is over X points, you just auto-succeed at the task. Speeds the game up immensely. Additionally, if you're writing a gig and need to see how likely it is a PC  will succeed, this is a nice tool. It will pull all non-Gamemaster actors into one window. Drop down or search bar for skills. Includes custom skills in the game. Highest base gets a purple tag. Everyone else gets green.

I have added the ability to roll a straight 1D10 that explodes/implodes as normal if you want to run a fast check for everyone and see who gets the highest result.

This is a macro script so import into your macro library, run as normal.
