Compatible with Foundry12/CPR v0.92.4

A collection of AI Slop-coded scripts & modules that I find useful to help run my game. These are offered as-is and standard caveats apply to homebrew stuff. I do not consider this created by myself or any of my own personal work, so feel free to mod to your heart's content. No attribution necessary due to AI slop. 

These are macros to run to help the game go a little easier.

Library TOC:
1. Crew Skill Comparison- A small script that pulls up every non-NPC and allows you to search for/pick a skill. It then shows you the skill level, the base stat it's attached to, and the base score. The highest score is highlighted purple for fast acquisition.
2. GM Screen- A script that allows you to build out a popout window with customized tabs and links to other scripts. Essentially similar to your hotbar but specifically for scripts. Think a script soundboard.
3. MacroExtractor- Tool for the original version of the GM screen. Select a folder/sub folder in your macro library, and it'll give you the UUID of every script in that folder. Useful for scripting.
4. Fluid Humanity Interface- Using the Edgerunners Mission Kit's fluid humanity rules. Run this script to bring up a popup window with all the entries in the EMK for humanity gain/loss as well as the option to add custom humanity gains/losses. Builds a card out that lets you roll for that character one event at a time, then posts the results to the chat channel along with warnings for advancing cyberpsychosis/disassociation.
5. Chargen script- A monster of a script to build out new characters. Due to some issues with generating new actors via script- specifically meat cyberware slots being missing- the script includes an empty character sheet json that needs to be imported as well and stored somewhere. New characters are copied off of this actor via hard coded UUID so keeping the document ID of the empty actor is important.
6. No Place Like Home DLC Worksheet- Two parts. The script itself and the journal you import for the addons. Simple worksheet to build out an HQ. Ability to export to journal for easier viewing.
7. CPR Theme Designer- Simple theme designer for CPR Foundry. This is a module, so copy the folder entirely into the modules sub folder for your foundry data path. See the specific readme.md for details.
