CPR Specific Theme Builder

After cranking out a couple of themes for the interface, I had a few ideas on a theme builder and I think it came out nicely. 

Due to how it functions, this is a module. Drop the folder in the zip into your modules folder, fire it up. It's accessible in the Configure Settings option to only GMs. I can probably change that to trusted players if I want to or even maybe add an option in this menu.

Functionality is fairly simple. Pick a seed color, generate suggestions. You will get 3 options each for shade or hue using basically color science. Click one to assign it. If you want to tweak, click the "custom" icon and set the color exactly how you want it. 

Name it, save to library. Reload with F5 and the theme should come up. If you want to edit, load the theme from the library, then save over the same name. It'll ask to overwrite. Say yes. 

Export JSON exports to a text box you can cut and paste into import JSON then "load into editor".  It will not save it automatically, you still have to save it. 

From my poking around there are 8 main CSS colors that go into the themes. The rest are based off of the dark theme for CPR as a fallback in case anything is missed. 

Standard caveats. Vibe coded, modify freely without attribution. Use at own risk, backup world first. Risk for this is pretty low but YMMV. V12 compatibility only.
